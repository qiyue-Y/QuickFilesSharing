# QuickFilesSharing

局域网剪切板 + 大文件快传服务。Windows 电脑上启动，同一局域网的电脑 / 手机用浏览器打开即可互传文本与文件，无需账号密码，无需装客户端。

## 快速开始

1. 首次安装依赖（任选其一）：
   - `uv sync`（推荐，仓库自带 uv.lock）
   - `pip install -r requirements.txt`
2. 启动：命令行执行 `python http_messages_share.py`（建议用项目自带虚拟环境：`.venv\Scripts\python.exe http_messages_share.py`）
3. 启动后自动打开浏览器；控制台列出本机所有局域网地址（标"推荐"的是默认路由出口），其他设备访问 `http://<局域网IP>:5000`

Linux 服务器：`gunicorn -c gunicorn.conf.py http_messages_share:app`

## 功能

- **剪切板**：按用户名隔离的文本剪切板，随手贴链接 / 命令 / 文本
- **大文件传输**：最大 30GB；上传 4 路分片并行；≤1GB 下载走页内并行分片（带进度和速度），>1GB 自动交给浏览器下载管理器接管（支持断点续传）
- **完整性校验**：每个文件记录 SHA-256（上传/合并时顺带算出），点击文件校验码可打开弹窗，内含接收端校验命令与 curl / aria2 命令行下载命令
- **传输可取消**：上传 / 下载均可中途取消，分片自动清理（启动时也会清扫超过 24 小时的残留分片）

## 目录说明

| 路径 | 用途 |
|---|---|
| `clipboards/` | 各用户剪切板文本（`<用户名>.txt`） |
| `files/<用户名>/` | 上传的文件；`.chunks/` 为分片临时目录（24h 自动清扫） |
| `logs/app.log` | 运行日志（20MB × 5 滚动） |
| `review-issues.md` | 待实施的问题清单（问题 / 解决方案 / 重要性 / 影响评估） |
| `docs/YYYY-MM-DD.md` | 按日期归档的改动记录（问题 / 原因 / 解决方法 / 日期，含实测验证） |

## 注意事项

- 用户名仅限字母 / 数字 / 下划线 / 连字符 / 中文，**不含空格和点**；用户名即存储目录名
- 服务不做鉴权，仅限可信局域网使用；端口固定 5000，启动时若发现已被占用（多半是旧实例没关）会拒绝启动并提示排查命令
- 局域网 HTTP 下浏览器禁用剪贴板 API 等安全特性，页面已做 `execCommand` 兜底
