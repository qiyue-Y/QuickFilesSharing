## 升级清单（改了什么 → 对应 skill 条目）

### 1. 排版体系（skill 4.1 / 9.B）

- v2 有 12+ 个零散字号（10/10.5/11/12/13/13.5/15/16/17/19/20/21/22）。收敛为阶梯：
  12（标签/注脚）/ 14（次级数据）/ 16（输入/序号）/ 20（清单体/文件名）/ 22（传输名）
  + clamp 巨字 h1 34-52、百分比 44-64、吞吐 84-160（签名保留）。
- 小字下限提到 12px：v2 的 10/10.5/11px 标签全部升到 12px（本仓库语境下 12px 是标签可读下限）。
- 字距体系：v2 有 15 个不同 letter-spacing（.01em 到 .36em）。收敛为：拉丁镜标签统一 .25em 全大写；
  中文一律不加字距（skill 语境裁定：全大写+拉字距仅用于拉丁字母）。
  中英双语标签拆成 `.zh` / `.en` 两个 span 分开处理（"局域网 + LAN"、"剪切板 + CLIPBOARD"）。
- 所有数据数字加 `font-variant-numeric: tabular-nums lining-nums`（状态值/尺寸/时间/速度/ETA/百分比）。
- `serif-text` 行高 1.65、`mono` 1.75、注脚 1.9，正文行高统一。

### 2. Georgia 数字决策（skill 9.B 排版纪律 + 6.A）

结论：数据巨字换 lining 数字，静态目录序号保留 Georgia oldstyle。

- v2 的 Georgia 是 oldstyle figures（3/4/5/9 下伸、6/8 上伸）。吞吐巨字每 140ms 重绘一次，
  末位数字变化时整串数字上下"呼吸"、左右抖动，且右侧 "MB/s" 单位跟着横移。
  仪器读数需要 lining + tabular；oldstyle 属于散文版面。
- `font-variant-numeric: lining-nums` 对 Georgia 无效（Georgia 没有 OpenType lnum/tnum 特性），
  因此新增专用数字栈 `--digits: "Didot", "Bodoni MT", "Times New Roman", Georgia, serif`：
  macOS 取 Didot、Windows 取 Bodoni MT（均为 lining），兜底 Times New Roman（lining 且等宽数字），
  同时声明 `font-variant-numeric` 在支持特性的字体上生效。应用于吞吐巨字与传输百分比。
  Didone 高对比衬线比 Georgia 的屏幕化粗衬线更贴"画廊展签"气质，仍属"超大衬线数据字"签名之内。
- 保留 oldstyle 的场合：文件序号 01-08、区块序号 01/02/03、衬线正文。它们是静态目录编号（从不重绘），
  下伸的 oldstyle 是展品目录的排版传统，与仪器读数的 lining 构成"目录 oldstyle / 仪表 lining"双声部。

### 3. 色彩对比锁（skill 4.2 / 4.5 / 14 节 Button & Form Contrast）

v2 半透明白共 7 档（.38/.45/.5/.55/.6/.62/.78/.8/.85/.92 中文字相关的就有 7 种），
其中 .38 = 2.7:1、.45 = 3.3:1、.5 = 3.7:1、.55 = 4.2:1，放在 10px 小字上全部不达 WCAG AA。
收敛为三档（对 #002FA7 基色实测对比）：

| 档位 | 用途 | 对 IKB #002FA7 | 对洪水深蓝 #002686 | 对 #001F7A |
|---|---|---|---|---|
| `--ink` 纯白 | 数值/标题/正文 | 10.7:1 | 13.0:1 | 14.2:1 |
| `--ink-2` .72 白 | 次级数据（尺寸/复制反馈/单位） | 6.1:1 | 7.3:1 | 7.9:1 |
| `--ink-3` .6 白 | 小标签/注脚/时间 | 4.7:1 | 5.5:1 | 5.8:1 |

- 全页文字对比下限 = .6 白在基色 IKB 上的 4.7:1，正文 ≥4.5:1 达标（大字余量更大）。
- 洪水层只会把底色换成更深的蓝，白字对比只升不降，两档蓝底下三档白全部 ≥4.5:1。
- 占位符从 .38（2.7:1）升到 .6（4.7:1）；时间戳从 .45 升到 .6；传输名从 .92 升到纯白。
- 非文字 UI 边界：按钮描边 .5 白 = 3.7:1、输入下划线 .45 = 3.3:1，均 ≥3:1（WCAG 1.4.11）。
- hover 行反白时蓝字对纯白 10.7:1、次级信息蓝字 75% 不透明度对白 5.6:1，均过线。

### 5. 交互态补全（skill 4.5）

- hover 白圆扩散填满：保留（主交互反馈）。
- 补 `:active` 物理反馈：按钮按下 `translateY(1px)`（配合 .09s 过渡）。
- `:focus-visible` 可见焦点环：白描边 1px + offset 4px（融入单色语言）。
  v2 的问题修正：焦点不再触发白圆填满（填满是 hover 语义），只显示环；
  反白行内按钮聚焦时环自动换成蓝色描边，避免白环消失在白底上。
- 输入框聚焦：下划线提为纯白 + `box-shadow: 0 1px 0 #fff` 加粗一倍（不引起布局位移）。
- aria：`flood`/`flash`/在线圆点 `aria-hidden`；复制反馈、发送反馈 `aria-live="polite"`；
  输入框补可见 `<label>`（v2 用 placeholder 兼任标签，违反 skill 4.6 "No placeholder-as-label"）。
- 本稿无纯图标按钮（全部带文字），无需 aria-label；此为逐项核对结论。

### 6. 动效审计（skill 5 节 MOTION MUST BE MOTIVATED + 6.B）

每条动画的动机（全部保留，均有动机，无"看着酷"项）：

| 动效 | 动机 |
|---|---|
| 洪水层 translateY 1.15s | 状态转换：总传输进度可视化（方向：从底部上涨） |
| 完成闪蓝 opacity 100ms/1200ms | 反馈：传输完成事件的整页确认 |
| 按钮白圆 scale .55s | 反馈：主交互的 hover 语义 |
| 按钮文字变色 .3s | hover 填满后的对比反转（同上动作的一部分） |
| 进度线 scaleX .3s linear | 状态转换：进度推进 |
| 在线圆点 breathe 2.6s | 语义状态：连接存活（唯一允许的状态点） |
| 静置速度微呼吸 | 语义状态：传输进行中（区别于冻结） |
| 剪切板新条目上浮 .5s | 反馈：发送动作确认 |
| 复制/发送提示浮现 .4s | 反馈：动作结果确认 |
| 文件行左滑淡出 .35s | 反馈：删除确认 |
| 入场错峰上浮 .8s | 层级：画廊灯亮起的阅读顺序引导 |
| 输入框下划线变色 .3s | 反馈：聚焦状态 |

- 性能（skill 6.A）：位移/出场全部只用 transform + opacity；颜色过渡仅 hover 期的 paint（无布局属性参与）；
  洪水层 blur(24px) 保持单层、固定定位、pointer-events none（skill 6.E）。
- `prefers-reduced-motion` 全量兜底（v2 为 0 处）：CSS 全局 `animation/transition: none`，
  JS 侧闪蓝直接跳过、洪水改为按 5% 分档跳变（避免每 140ms 高频位移）、入场瞬时完成。
- 入场隐藏态加 `html.js` 门控：JS 被禁用时页面不再白屏（v2 缺陷）。
