# demo-v2/日与线 — 设计演示

`index.html` 是界面设计升级的静态案例，**不接后端**：所有数据为本地模拟，双击浏览器打开即可（零外部依赖，离线可用）。

- 设计方向：与「留白呼吸」同族——场绝对平（纸白、墨字、发丝线、零阴影零渐变），实物只做挂饰；公共件同为**黄铜长尾夹**（剪切板纸角）与**朱砂印章**（状态动作）
- 结构张力来自 **C4 日与线**：页首一条横贯的发丝线就是磁盘——实线段=已用（末端刻度标注 `已用 62% · 615/985 GB`）；线上方一颗朱砂圆点=今日活跃度，**横坐标=真实时钟（00–24 沿线升落），高度=当前传输速率**（空闲贴地、满速升至线上方 96px）；日头身后拖一条发丝山脊线=今天的活跃轨迹。一眼读两件事：多满、多忙。日头垂一根细影线（日晷晷针）落到线上标出当下时刻

## 交互

- 打开 1.4 秒后自动演示一轮三文件排队上传：传输中日头爬升、山脊抬腕，传完回落
- 剪切板：编辑→保存=盖「存」；清空→确认=盖「删」
- 上传：拖入真实文件按真实名字/大小模拟进度；超 30GB 或磁盘余量不足→投放区盖「拒」+toast
- 文件库：完成态文件行首常驻 6mm 印章痕迹（传）；删除→确认→盖「删」后折叠，磁盘线段回落
- 切换用户（用户 / 同事）、直达分享与下载为示意 toast
- 参数：`?static=1` 跳过自动演示与入场动画（评审截图用）

## 设计规则（生产化时沿用）

- 场：底 `#FAF9F6`、墨 `#191817`、发丝线 `rgba(25,24,23,.14)`；容器零阴影零圆角体系
- 唯一色彩 = 朱砂 `#B23B24`，只出现在两处：印章（动作痕迹）与日头（时间痕迹）——色彩语义="发生过的事"
- 磁盘不做百分比大数字，做成线段+刻度标注；活跃轨迹用 SVG polyline（`vector-effect:non-scaling-stroke` 保持 1px），每 600ms 采样一点、保留 90 点
- 日头/晷针位移：`left` 线性 0.6s（跟时钟走），`bottom` 1.2s 缓动（速率平滑）
- 印章与长尾夹实现同「留白呼吸」：feTurbulence 毛边+噪点 mask；纯 CSS 黄铜夹
- 数字/哈希/体积一律等宽 + `tabular-nums`
- `<960px` 工作区折单列，日与线区保持全宽；`prefers-reduced-motion` 关闭动画
