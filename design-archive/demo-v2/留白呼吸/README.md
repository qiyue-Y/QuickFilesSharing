# demo-v2/留白呼吸 — 设计演示

`index.html` 是界面设计升级的静态案例，**不接后端**：所有数据为本地模拟，双击浏览器打开即可（零外部依赖，离线可用）。

- 设计方向：**场绝对平 × 物绝对真**。页面本身只有纸白底、墨色文字、发丝线，无卡片阴影无渐变；全页仅有的"实物"是两只——剪切板纸角的**黄铜长尾夹**（唯一带高光和投影的件）与状态变化时砸下的**朱砂印章**（唯一带色彩与肌理的件）
- 结构张力来自 **C2 留白呼吸**：页面留白率随状态收缩/回吐——静置时上下留白 12vh、栏间距 72px；传输开始"吸"进busy 态（3.5vh / 26px，传输队列展开）；全部完成后"回吐"到 settle 态，再归静置。右下角有实时「留白 %」读数，评审截图可直接看出呼吸幅度

## 交互

- 打开 1.4 秒后自动演示一轮三文件排队上传（逐个完成、盖章、写进文件库、磁盘水位抬升、页面呼吸）
- 剪切板：编辑→保存=盖「存」；清空→确认=盖「删」
- 上传：拖入真实文件按真实名字/大小模拟进度；超 30GB 或磁盘余量不足→投放区盖「拒」+toast
- 文件库：删除→确认→行上盖「删」后折叠，磁盘回落；完成态文件行首常驻 6mm 印章痕迹（传）
- 切换用户（用户 / 同事）、直达分享与下载为示意 toast
- 参数：`?static=1` 跳过自动演示与入场动画（评审截图用）

## 设计规则（生产化时沿用）

- 场：底 `#FAF9F6`、墨 `#191817`、发丝线 `rgba(25,24,23,.14)`；容器零阴影零渐变零圆角体系（1px 直角）
- 唯一色彩 = 朱砂 `#B23B24`，只出现在印章（动作痕迹）里；绿/红/黄状态色全部取消，状态用文字与印章表达
- 印章：SVG `feTurbulence+feDisplacementMap` 做边缘毛糙、噪点 mask 做印泥颗粒；动画=从 2.4 倍高处砸下带 7° 旋转回正到 -4°，停留 0.7s 后缩小淡出，同时在行尾留下 17px 常驻痕迹；按压瞬间印章底缘有一圈极淡的纸面压痕（radial-gradient，属于事件的一部分）
- 长尾夹：纯 CSS（黄铜渐变梯形 + 两枚银色线柄 + drop-shadow），夹在纸角上沿，pointer-events:none
- 数字/哈希/体积一律等宽 + `tabular-nums`；速度大读数用细字重（font-weight 200）
- 呼吸：`--pad-y/--gap` CSS 变量 + 1.1s `cubic-bezier(.22,.8,.18,1)`；队列展开用 `grid-template-rows:0fr→1fr`
- `<1024px` 折单列；`prefers-reduced-motion` 关闭全部动画
