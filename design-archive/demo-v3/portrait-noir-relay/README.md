# portrait-noir-relay — 前端设计演示（demo-v3）

`index.html` 是界面设计升级的静态案例，**不接后端**：所有数据为本地模拟，双击浏览器打开即可（零外部依赖，离线可用；`madame-x-cutout.png` 为萨金特《X夫人》公版剪影， Wikimedia Commons 来源）。

- 设计方向：**古典极简 / 肖像 Noir**——纸白底、墨色衬线大字、发丝线、单一勃艮第红 accent，左侧《X夫人》剪影作底纹；登录后剪影淡出为背景（opacity 0.30，移动端 0.16）
- 打开为登录门，输入名字进入工作台；1.6 秒后自动演示一轮上传（48.2 MB → 1.38 GB → 31.5 GB 触发单文件上限拦截）
- 功能（全部假数据）：传输队列（逐个排队、2px 细线进度条 scaleX、速度 112.6 MB/s 实测档、剩余时间、完成时 SHA-256 校验闪动）、30 GB 单文件上限与磁盘余量上传前拦截、顶栏 1px 当前进度线与磁盘水位计（43.8/101.0 GB，≥80% 变 accent）、用户切换菜单（用户 / 同事 / 以新名字进入，剪切板与文件各自独立）、文件行 SHA-256 短码、文件详情弹窗（全量校验码 + 复制 + 下载 + 删除）、toast、剪切板保存带"上次保存 HH:MM · N 字"
- 追加参数：`?nodemo=1` 跳过自动演示（评审截图用）

## 设计规则（生产化时沿用）

- 色板：纸白 `#f5f6f3`、墨 `#20211f`、muted `#777a73`、发丝线 `#d8dad4`/`#b5b8b0`、单一 accent 勃艮第红 `#793f48`；成功 `#476651`、错误 `#9a3f45` 只作状态色
- 字体：衬线 `Iowan Old Style / Baskerville`（标题、人名、百分比读数）、无衬线 `Aptos / Segoe UI / 微软雅黑`（正文）、`Cascadia Mono / Consolas`（校验码与数字读数，`tabular-nums`）
- 形状语言：直角（半径 0，按钮 2px）、零阴影零渐变，层级靠 1px 发丝线与留白；全页 2.5% 透明度 feTurbulence 颗粒
- 动效统一 `cubic-bezier(0.22,1,0.36,1)`：队列展开 `grid-template-rows 0fr→1fr`、进度 `transform: scaleX`（不触发重排）、弹窗上浮 0.45s、面板横移 0.48s、文件行错峰入场（45ms 级差）；`prefers-reduced-motion` 全局关停
- 弹窗/菜单/toast 均为纸面直角件：无投影、1px 墨线或墨底反白

## 与生产页的对应

| demo 中的设计 | 生产对应 |
|---|---|
| 上传前磁盘余量与 30 GB 上限拦截 | R3-P0-1 空间预检 |
| 队列逐个完成、写库、抬升磁盘水位 | 生产分片上传流程 |
| 用户切换、每用户独立剪切板与文件 | `files/<用户名>/`、`clipboards/` 隔离 |
| 文件详情弹窗 + SHA-256 + 页面内校验提示 | `.hashes.json` 校验闭环（JS SHA-256 实测 43 MB/s） |
