# Monet Breeze

QFR 的独立 UI demo。直接打开 `index.html` 即可预览，不需要启动后端。

## 内容

- 同一个页面内完成登录页到工作台的过渡。
- 登录、记住用户名和剪切板保存使用浏览器本地存储。
- 文件选择、拖放、进度、下载和删除均为视觉演示，不会请求生产接口。
- 已处理桌面端和移动端布局，并支持 `prefers-reduced-motion`。

## 画作素材

Claude Monet, *Woman with a Parasol - Madame Monet and Her Son*, 1875。

来源：[Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Claude_Monet_-_Woman_with_a_Parasol_-_Madame_Monet_and_Her_Son_-_Google_Art_Project.jpg)。原作及其忠实数字复制品为公版素材。
