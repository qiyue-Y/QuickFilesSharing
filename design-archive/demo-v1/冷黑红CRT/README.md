# demo4/ — 前端设计演示(第四方向)

`index.html` 是界面设计升级的静态案例,**不接后端**:所有数据为本地模拟,双击用浏览器打开即可(纯系统字体栈,无任何外部依赖,离线可用)。

- 设计方向:**工业粗野主义 × 战术遥测 CRT 终端**(industrial-brutalist),与 demo/(深色单蓝)、demo2/(暖白编辑风)、demo3/(银灰紫 Bento)区分
- 打开先走一段启动门开机自检(打字机逐行,点击任意处跳过),随后自动以记住的操作员进入工作台
- 进入 1.4 秒后自动演示一轮三文件排队上传(48.2MB → 3.42GB → 18.7GB,逐个完成、写进清单、抬升磁盘水位)
- 可交互:上传队列(拖入真实文件按真实名字/大小模拟进度,超 30GB 或磁盘余量不足会演示拦截)、文件详情弹窗、页面内一键校验拖放区、删除/清空确认弹窗、切换用户、退出后的身份门(需手动进入)、toast、系统日志
- 追加参数:`?view=modal` 直接打开文件详情弹窗;`?static=1` 跳过开机动画与自动演示;`?gate=1` 停在启动门不自动进入
- 模拟速度:上传 112.6 MB/s(千兆局域网实测档),页面内校验 43 MB/s(页面内 JS SHA-256 实测值);墙钟按 ×28 加速,页面内显示的 RATE/ETA 按未加速换算
- `_shot_desktop.png` / `_shot_mobile.png` 为整页参考截图

## 设计规则(生产化时沿用)

- **暗底 CRT 终端**:底 `#0A0A0A`、正文磷光白 `#EAEAEA`;全页叠加扫描线(2px 横纹)+ 噪点(SVG feTurbulence)+ 暗角,固定 HUD 外框与四角十字
- **单一警示红** `#E61919`:仅用于强调(描边巨型数字 `:5000`、TX 进度条、删除/中止 hover、警示斜纹条、确认弹窗);终端绿 `#4AF626` 只许出现在状态指示灯(LINK ACTIVE 灯、校验 PASS 灯),不作正文色
- **全等宽 + 双语标签**:数据/正文一律等宽(Cascadia Mono/Consolas 栈),标签 `[ TEXT BUFFER / 文本缓冲 ]` 英文大写 + 空心中文;巨型报头用 Arial Black 栈 `clamp()` 缩放,字距收紧
- **0 圆角、0 渐变按钮、0 阴影模糊**:按钮方角描边、hover 反色、按压位移 1px;弹窗用纯色硬投影(无 blur);分隔靠 1px 网格 `gap:1px` 拼出舱室线
- ASCII 作图标与进度:上传/下载用 `█░` 块符进度条、`///` 方向符、`[ ]` 框名、`●` 状态灯,不引入图标库和 emoji
- 磁盘水位为 56 格分段仪表,上传期间用红色格显示**预计占用**(含合并期 ×1.05 头寸)
- 响应式:<1080px 双栏折单栏;<680px 收起 HUD 框、报头纵排、清单表横向滚动;`prefers-reduced-motion` 关闭闪烁/动画
- 语义标签:`<output>`/`<code>`/`<kbd>` 风格等宽读数,文件名走 data-* + 事件委托,不拼 onclick 字符串(与生产页同款防注入做法)
