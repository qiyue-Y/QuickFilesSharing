# demo3/ — 前端设计演示（第三方向）

`index.html` 是界面设计升级的静态案例，**不接后端**：所有数据为本地模拟，双击用浏览器打开即可（字体已 base64 内嵌，无任何外部依赖，离线可用）。

- 设计方向：**银灰浅底 / 墨黑大字 / 单一紫色 accent 的 Soft Structuralism + 不对称 Bento**，与 demo/（深色单蓝）、demo2/（暖白编辑风）区分
- 打开即进入工作台演示态，页面加载 1.2 秒后自动演示一轮三文件排队上传（上传中会实时写进文件库、抬升磁盘水位）
- 可交互：上传队列（拖入真实文件会按其名字、真实大小模拟进度，超 30GB 会演示拦截）、文件详情弹窗、删除/清空确认弹窗、切换用户、退出后的身份门、toast
- 追加参数 `?view=modal` 直接打开文件详情弹窗；`?static=1` 跳过入场动画（评审截图用）
- 模拟速度：上传 112.6 MB/s（千兆局域网实测档），页面内校验 43 MB/s（页面内 JS SHA-256 实测值）
- `_shot_desktop.png` / `_shot_mobile.png` 为整页参考截图

## 设计规则（生产化时沿用）

- 浅色主题：底 `#F4F5F7` 银灰、卡芯纯白，墨黑 `#101318` 正文；单一 accent 紫 `#6E56CF`，绿/红/黄只作状态色
- 所有卡片用双层包边：银灰外壳（24px 圆角、发丝线）+ 白色内芯（18px 圆角），按钮/输入为全圆角 pill
- 主按钮带「按钮内按钮」尾随圆钮，hover 时内钮位移产生动势；按压 scale(0.97)
- 数字、哈希、命令、体积一律等宽字体 + `tabular-nums`；标题/数字用内嵌 Space Grotesk（拉丁），中文回退微软雅黑
- 图标为 24 网格描边图形（stroke 1.25 细线），内联 sprite，零外部依赖
- 动效统一 `cubic-bezier(.32,.72,0,1)`；进度条用 `transform: scaleX`（不触发重排）；入场为 IntersectionObserver 模糊上浮，支持 `prefers-reduced-motion`
- 布局：<1024px Bento 折叠单列，<768px 隐藏文字标签、操作钮收成图标
