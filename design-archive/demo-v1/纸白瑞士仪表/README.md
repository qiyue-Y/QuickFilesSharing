# demo6/ — 前端设计演示（第四方向）

`index.html` 是界面设计升级的静态案例，**不接后端**：所有数据为本地模拟，双击用浏览器打开即可（系统字体 + 内联 SVG，零外部依赖，离线可用）。

- 设计方向：**瑞士国际主义 / 仪表版式** —— 纸白底、墨黑结构线、单一朱橙 accent、直角零投影、等宽数字，整体像一张打印的精密表格；与 demo/（深色单蓝）、demo2/（暖白编辑风）、demo3/（银灰紫 Bento）区分
- 打开即进入工作台演示态，页面加载 1.2 秒后自动演示一轮三文件排队上传 + 第四个大文件触发空间预检拦截（队列红色态 + toast + 日志记录）
- 可交互：上传队列（拖入真实文件会按其名字、真实大小模拟进度）、文件详情弹窗（含接收端校验拖放区）、删除/清空确认弹窗、切换用户、退出后的身份门、toast、剪切板保存/复制/清空
- 追加参数 `?view=modal` 直接打开文件详情弹窗；`?view=gate` 直接打开身份门；`?static=1` 跳过入场动画（评审截图用）
- 模拟速度：上传 112.6 MB/s（千兆局域网实测档），页面内校验 43 MB/s（页面内 JS SHA-256 实测值）
- `_shot_desktop.png` / `_shot_mobile.png` 为整页参考截图

## 设计规则（生产化时沿用）

- 浅色主题：底 `#FAFAF7` 纸白、卡芯纯白，墨黑 `#141414` 结构线与正文；单一 accent 朱橙 `#FF4D00`，绿/红/黄只作状态色
- 全部直角（radius 0），层级靠 1px 结构线（`#141414`）与发丝线（`#DAD8CF`）划分，不用投影；弹层用 8px 硬偏移阴影抬升
- 顶栏是仪表条：字标 + 传输日志跑马灯（两侧渐隐遮罩，hover 暂停）+ 迷你磁盘水位 + 分享/用户
- 进度条为分段式（LED 表风格）：填充层之上用 repeating-gradient 刻出等宽缺口
- 磁盘水位计带 0/25/50/75/100 刻度：≥80% 变朱橙（hot），≥95% 变红（crit）
- 数字、哈希、命令、体积一律等宽字体 + `tabular-nums`；系统字体栈（Segoe UI / 微软雅黑 / Cascadia Code），零外链
- 图标为 24 网格描边图形（stroke 1.6 方头），内联 sprite；类型徽章用扩展名大写字母 + 方框
- hover 反白：文件行/顶栏按钮悬停整块反色（墨底纸字），动效统一 `cubic-bezier(.2,0,0,1)`
- 布局：12 列结构网格（masthead 7+5、工作区 7+5、文件库通栏）；<1080px 折叠单列，<760px 隐藏时间/哈希列、按钮收成图标，<560px 大小折进副行
- 文件名走 data-* + 事件委托，不拼 onclick 字符串（与生产页同款防注入做法）
