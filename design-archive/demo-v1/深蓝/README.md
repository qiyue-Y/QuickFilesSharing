# demo/ — 前端设计演示

`index.html` 是界面设计升级的静态案例,**不接后端**:所有数据为本地模拟,双击用浏览器打开即可(无任何外部依赖,离线可用)。

- 打开即进入工作台演示态,页面加载 1.2 秒后自动演示一轮多文件排队上传
- 可交互:上传队列(拖入真实文件会按其名字大小模拟进度)、文件详情弹窗、删除/清空确认弹窗、切换用户、toast
- 追加参数 `?view=modal` 可直接打开文件详情弹窗(评审截图用)
- 文件删除后列表清空可见空状态;模拟上传速度约 112.6 MB/s(千兆局域网实测档),一键校验按 43 MB/s 模拟(页面内 JS SHA-256 实测值)

## 设计规则(生产化时沿用)

- 深色主题锁定,单一 accent 蓝 `#5ea0ff`;绿/红/黄只作状态色,不做装饰
- 圆角体系:卡片 12 / 按钮·输入 8 / 小徽章 6 / 进度条 pill
- 数字、哈希、命令、体积一律等宽字体 + `tabular-nums`
- 图标为 24 网格描边图形(stroke 1.75),内联 sprite,零外部依赖
- 类型徽章用扩展名大写字母,单色,不引入第二套彩色体系
