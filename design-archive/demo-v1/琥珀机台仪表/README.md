# demo5/ — 前端设计演示（琥珀机台）

`index.html` 是界面设计升级的静态案例，**不接后端**：所有数据为本地模拟，双击用浏览器打开即可（零外部依赖，离线可用）。

- 设计方向：**琥珀机台 —— 暖炭黑底盘 + 单一琥珀 accent + mono 读数 + 左侧仪表面板栏（立式磁盘 LED 表）**。与 demo/（深色单蓝·顶栏双栏）、demo2/（暖白编辑衬线）、demo3/（银灰紫 Bento）、demo4/（冷黑警示红 CRT 粗野）、demo6/（纸白朱橙瑞士仪表）并行竞稿：同为深色但色温、accent、布局结构（侧栏 vs 顶栏/终端框架）、字体策略（mono 读数 + 雅黑正文 vs 全等宽）均不同
- 打开即进入工作台演示态，1.2 秒后自动演示一轮三文件排队上传（逐个完成、写进文件库并抬升磁盘水位）
- 可交互：上传队列（拖入真实文件会按其名字、真实大小模拟进度，超 30GB 演示拦截）、文件详情弹窗（SHA-256 / 四端校验命令 / 命令行下载 / 直达链二维码 / 页面内一键校验）、删除与清空确认弹窗、切换用户、退出后的身份门、toast
- 参数：`?view=modal` 直开文件详情弹窗；`?shot=1` 定格在传输中（61% 进行中 + 排队各一条，评审截图用，`_shot_*.png` 即此状态）；`?static=1` 跳过入场动画
- 模拟速度：上传 112.6 MB/s（千兆局域网实测档），页面内校验 43 MB/s（页面内 JS SHA-256 实测值）；磁盘数 101.0/57.2 GB 取自实际服务器

## 设计规则（生产化时沿用）

- 暖炭黑底盘 `oklch(19% 0.012 75)`、仪器面板 `oklch(23%)`、凹槽（inset）更深、凸起用更亮的面——高度靠面亮度表达，无彩色阴影、无玻璃拟态、无文字发光
- 单一 accent 琥珀 `oklch(80% 0.155 78)`，只给读数类数字（速度/百分比/可用容量/哈希/链接）、主按钮、焦点环、LED；绿/红/黄只作状态色
- 布局：左侧仪表面板栏（品牌 / OPERATOR / STORAGE 立式 24 格 LED 磁盘表 / LINK 地址）+ 主台（剪切板控制台 · 文件货舱）；≤1024px 侧栏折为顶栏、LED 表转横向；≤640px toast 改底部弹出、文件行体积并入名字下方
- 方角仪器面板（6/4px 圆角），进度条用 `transform: scaleX`（不触发重排）
- 数字、哈希、命令、体积一律等宽字体 + `tabular-nums`；图标为 24 网格描边图形（stroke 1.75），内联 sprite，零外部依赖
- 动效仅三原语：入场 reveal（LED 表自底向上逐格点亮）· 传输中 LED 呼吸 · 进度 scaleX；全部响应 `prefers-reduced-motion`
- 文件名走 data-* + 事件委托，不拼 onclick 字符串（与生产页同款防注入做法）
