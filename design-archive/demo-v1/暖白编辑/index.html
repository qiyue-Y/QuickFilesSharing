下载后怎么校验文件完整性？ +
把命令复制到接收端电脑执行，文件名换成实际下载到的名字（浏览器遇到同名文件可能加了 (1)），拿输出的校验码和文件行里的 SHA-256 对比。只比对 64 位十六进制字符，大小写和空格不用管。
Windows · CMD certutil -hashfile "文件名.zip" SHA256
Windows · PowerShell Get-FileHash -Algorithm SHA256 "文件名.zip"
Linux sha256sum "文件名.zip"
macOS shasum -a 256 "文件名.zip"
