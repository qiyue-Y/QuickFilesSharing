# 2026-09-21

- 问题：本地启动要手动开终端、敲命令，日志窗口一闪就关，看不到持续输出。
- 原因：没有一键启动入口；双击 ps1 默认还会被记事本打开。
- 解决方法：
  - 根目录新增 `start.ps1`：`Set-Location $PSScriptRoot` 后前台 `uv run python http_messages_share.py`，日志实时打到窗口并同时落 `logs/app.log`；进程退出后 `Read-Host` 停住不闪退。文件存为 UTF-8 with BOM（PS 5.1 按 GBK 解析无 BOM 文件，中文注释会把引号吃坏导致语法错）。
  - 桌面新增快捷方式 `QuickFilesSharing.lnk`：目标 `powershell.exe -NoExit -ExecutionPolicy Bypass -File <项目>\start.ps1`，工作目录项目根，图标用 `.venv\Scripts\python.exe`。
- 验证：`Parser::ParseFile` 语法检查 SYNTAX OK；快捷方式 Target/Args/WorkDir/Icon 回读正确。未实际拉起 5000 端口（避免占用用户实例）。
